规范 ​

这些页面面向开发者，总结当前 Piwork 实现，依据源码项目已有规范编写，不另行定义 API 或包格式。

源码核对版本为 326837881f2a，核对日期为 2026 年 10 月 6 日。安装指南使用已有的公开 0.1.0 候选 Docker 镜像集；固定引用和构建来源单独记录在安装元数据中。源码与镜像交付有各自的版本。

范围本站文档权威来源
可携带 WorkWork 规范包格式与 portable-work
受管理能力Service 规范work-services与 MCP 工具
智能执行Harness 规范agent-conversation与 piwork-brain

状态标记 ​

  • 当前行为 / 格式： 已实现的行为和源码契约。
  • 实验性： 已有实现，但契约和交互还在演进。
  • 未来方向： 产品目标，不是已实现的保证。

遇到不一致时，以当前实现为准。可以提交 Issue，附上命令、镜像版本和实际结果。

当前交付边界 ​

Core 通过 Unix API 管理一台本地 Linux Docker Engine。Docker 交付面向 linux/amd64、Engine 28+ 和 Compose 2.24+。Go CLI 有 Windows 和 Linux 构建目标；尚未完成的原生 Windows 验收项见源码的 CLI 平台指南。

Work 需要就绪的运行镜像和模型配置。Core 关闭时会停止受管理的运行容器，并保留持久状态。关闭 Desktop 或 CLI 不会停止 Work。
