# 第一个 Work

先按[快速开始](/zh/guide/quick-start.html)打开 Piwork，完成账号和模型设置，等待依赖就绪，再点击 **Open workbench**。

## 创建并打开

点击 **New Work**，输入名称，例如「我的内容工作室」。等待 Work 就绪，打开 **Chat**，发送一条具体需求：

> 帮我做一个内容工作室，整理播客、视频和写作灵感。需要分类、搜索、详情页，并保存数据。

在对话中观察执行结果。应用准备好后，从 **Service** 打开它，实际使用搜索、分类和内容详情。

## 在同一个 Work 中继续修改

回到 Chat，描述下一步需求：

> 加一个发布日历，保留已有灵感。点击日历条目时，打开原来的内容详情。

核对修改后的应用以及原有数据。对话、应用和文件都留在这个 Work 中，下一次可以接着改进。

**Files** 用于浏览、上传和下载工作空间文件；**Settings** 保存配置，按页面要求显式 **Apply** 后生效。

## 带走整个 Work

1. **停止 Work**，等待停止完成。
2. 从 Work 菜单导出 `.work` 文件。
3. 在另一套兼容的 Piwork 中选择导入，上传文件并等待完成。
4. 导入得到停止状态的 Work，由你点击 **Start**。
5. 等待就绪，打开应用，检查原有内容并继续工作。

接收方需要配置自己的模型凭据，并准备兼容的运行环境。`.work` 导出用于迁移 Work，不等同于完整安装备份。包内包含工作区内容和私有历史，也包含你存入其中的凭据；分享前确认内容，只交给可信接收者。

## 下次继续

关闭浏览器不会停止 Work。需要停止某个 Work 时，从工作台菜单选择 **Stop**；下次点击 **Start** 后继续。

结束整次本地使用时，通过桌面启动器正常停止 Piwork，等待关闭完成，保留原数据目录。再次打开同一个启动器即可返回。
