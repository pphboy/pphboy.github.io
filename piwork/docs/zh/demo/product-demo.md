# 产品演示

**创造。进化。随处开工。**

这段 70 秒视频围绕同一个想法展开：AI 将它变成真正运行的内容工作室，在保留原有灵感的基础上加入发布日历，再把整个 Work 带到另一套 Piwork 环境中继续使用。

<ProductDemo />

## 视频展示了什么

1. **创造：** AI 在 Piwork 内创建 **My Creative Studio**，提供灵感卡片、分类、状态、搜索与持久化数据。
2. **进化：** AI 为同一个应用加入发布日历，保留六条原始灵感，并从日历打开已有记录。
3. **迁移：** 停止 Work 并导出 `.work` 文件，在独立 Piwork 安装中导入、显式启动，再次验证应用、日历与原始记录。

## 录制与验证范围

画面来自 Piwork 0.0.7 的真实操作，剪辑缩短了模型执行和部署的等待时间。

迁移验证使用同一 Linux x86-64 主机上的两套独立 Piwork 安装，两端分别准备了兼容的运行镜像，并配置了各自的模型凭据。
