What is Piwork? ​

Piwork packages a runnable AI workspace into a portable unit called a Work. Keep the applications, files, conversation history, and execution environment together, then export them and continue on another Piwork installation.

ConceptRole
WorkThe workspace. Holds the environment and its durable state.
ServiceThe capability. Runs an application, API, or other container service.
HarnessThe intelligence. Uses models, tools, and workspace-specific instructions to understand and operate the Work.

The Harness can help build and change the workspace it runs in. Its instructions, Skills, packages, and verified experience can evolve with that Work.

Default Web development uses a reusable Python + NiceGUI + SQLite environment. Standard templates adopt deployed updates automatically; see Web Development for usage and maintenance.

How it works ​

Create → Run → Evolve → Export → Share → Import → Continue

Export a stopped Work as a .work file. Import it into a compatible installation and start it explicitly. The target supplies its own model credentials.

Example: Kanban Work ​

A board, its data, an application Service, and a Harness that helps build and operate it form one workspace. Read the Kanban walkthrough. The Kanban example's downloadable package and recording are still being prepared.

Get started ​

Start Piwork with one command: one Docker container, then open the server IP to configure the administrator, model and CoreRuntime and use the full workbench. No CLI, domain or initialization environment is required. Optional docker-compose.yml. State: published. Images are published and anonymously verified.
